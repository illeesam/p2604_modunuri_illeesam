현재 위치: shopjoy_v260828_mfe/bo-ap-home/  (컨테이너 폴더 바로 밑, 셸(bo-ap-global/)
          및 실제 프로젝트 복제 도메인 11개 레포(bo-ec-mb/bo-ec-pd/bo-ec-od/bo-ec-pm/
          bo-ec-dp/bo-ec-cu/bo-ec-cm/bo-ec-st/bo-md/bo-sy/bo-zd)와 전부 완전한 형제.
          폴더명 앞의 "bo-" 는 정렬용이 아니라 의미론적 접두어(2026-08-29,
          ab-home→bo-ab-home 전면 변경) — 원본 프로젝트의 bo-/fo- 파일명 규칙(관리자
          화면=bo-, 사용자 화면=fo-)을 폴더 단위로 확장한 것으로, 이 폴더들이 전부
          관리자(Back Office) 화면이라는 뜻이다. bo- 뒤의 "aa-"/"ab-" 서브접두어는
          예전(2026-08-28) 정렬 관례를 그대로 이어받은 것 — 셸(당시 bo-aa-main, 이후
          bo-aa-global)이 파일탐색기 최상단 + 이 폴더(bo-ab-home)보다 앞에 오도록
          aa < ab 알파벳순으로 고정한 것뿐이다. 2026-08-29 후속 재구조화로 셸과 이
          폴더의 서브접두어가 "aa"/"ab" → 둘 다 "ap"로 통일되어(`bo-ap-global`/
          `bo-ap-home`) 지금은 순수 알파벳 정렬 의미는 사라졌지만, 여전히 "이 둘은
          컨테이너 최상단에 고정 배치되는 특수 폴더"라는 표식으로 유지한다 — 실제
          git 레포명은 여전히 shopjoy-mfe-domain-home 이 맞다, 로컬 접두어를
          레포명에 그대로 쓰지 않는다.
